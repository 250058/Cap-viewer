Capstone 실험 파일을 휴대폰에서 그대로

PASCO Capstone에서 저장한 .cap 파일의 페이지, 설명문, 그림, 그래프, 표를 Capstone처럼 볼 수 있어요.

파일은 이 기기 안에서만 처리되며 어디에도 업로드되지 않습니다.

사용 팁

  • 위쪽 페이지 탭으로 Capstone의 페이지를 넘겨 보고, 아래 ◀ ▶로도 이동할 수 있어요.
  • 휴대폰에서는 화면에 맞게 세로로 정리해서 보여 주고, 원본 배치를 누르면 Capstone 화면 그대로 볼 수 있어요.
  • 그래프의 축 이름을 누르면 측정값을 바꿀 수 있고, 두 손가락으로 확대, 탭해서 값을 읽을 수 있어요.
  • 카카오톡·드라이브로 받은 파일은 먼저 휴대폰에 저장한 뒤 파일 선택에서 고르세요. 홈 화면에 추가하면 인터넷 없이도 열립니다.
